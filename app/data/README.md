# app/data

## municipalities.csv

市町村と特別区の一覧（1,741件）。列は `code`（全国地方公共団体コードの上5桁）・`prefecture`（都道府県名）・`name`（市区町村名）。

- 出典：「都道府県コード及び市区町村コード」（総務省）（https://www.soumu.go.jp/denshijiti/code.html ）（令和6年1月1日更新の Excel を、2026年11月20日に利用）を加工して作成
- 利用の決まり：[公共データ利用規約（第1.0版）](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0)（総務省ホームページの「著作権について」による）
- 加工の中身（`scripts/build_municipalities.py`）：
  - 6桁のコードから、末尾の検査数字を除いて5桁にした
  - 都道府県だけの行・ふりがな・カナの列を除いた
  - 政令指定都市の区（別のシート）は入れていない。市そのものは入っている
  - 北方領土の6村（コード 01695〜01700）は入れていない（住む町・事務所のある町として選べないため）
- この一覧は、総務省が作ったものではありません。合併などで変わったときは、新しい Excel から作り直します（`flask sync-municipalities` は、無い行を足すだけです。名前を直す・消すことはしません）

作り直し方：

```
python scripts/build_municipalities.py ダウンロードした.xlsx
```

## 決まり

- 置いてよいのは、市町村の名前とコードだけです。実在の町に、デモ・テストの事務所・人・数字を結びつけません
- デモの数字は、コードが 9 で始まる架空の町（みなみ市・きた町・ひがし村）だけに置きます
